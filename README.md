# FolderManager
Thank you for choosing latest release FolderManager v1.0.0
An App designed to keep your files secure! Only for MacOS

Double-Click on the Installer and after the installation type folder-manager and wait for the opinion on the screen

Commands:
1. Inspect
2. Set password -- if password is not displayed, its okay!
3. Exit

Watch an Youtube Video for Help!

You have to Manually delete the old folder parent (the folder which you created dmg)

Your hidiutil is located in /usr/bin/hdiutil named Private. Noted: Private can be opened without an password
